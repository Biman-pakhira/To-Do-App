# To-Do App

A simple and elegant to-do list application built with vanilla JavaScript, HTML, and CSS.

## Features

- ✅ Add new tasks
- ✅ Mark tasks as completed
- ✅ Delete tasks
- ✅ Clean and responsive design
- ✅ Local storage (tasks persist in browser)

## Demo

[View Live Demo](https://biman-pakhira.github.io/To-Do-App/)

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6+)

## How to Use

1. Clone the repository:
   ```bash
   git clone https://github.com/biman-pakhira/To-Do-App.git
   ```

2. Navigate to the project directory:
   ```bash
   cd To-Do-App
   ```

3. Open `index.html` in your web browser.

## Features in Detail

- **Add Tasks**: Type your task in the input field and click "Add" or press Enter
- **Complete Tasks**: Click the checkbox next to a task to mark it as completed
- **Delete Tasks**: Click the "Delete" button to remove a task
- **Responsive Design**: Works well on both desktop and mobile devices

## Browser Support

This app works in all modern browsers that support ES6 JavaScript features.
